# Technity Company Profile Website

Website yang memberikan informasi publik terkait komunitas atau startup Technity

## Fitur Utama
- **Beranda**: Halaman pertama kali yang dilihat user. Berisi Headline, Sub-Headline, CTA, dan Visual Utama
- **Tentang**: Halaman yang berisi profil singkat dan visi-misi
- **Layanan**: Halaman ini menjelaskan layanan apa yang ditawarkan oleh perusahaan
- **Kontak**: Tempat user dapat mengontak perusahaan

## Prasyarat

Sebelum membuka atau mengembangkan website ini, pastikan kamu memiliki:

- **Web Browser** (Google Chrome, Brave Browser, Microsoft Edge, atau sejenisnya)
- **Code Editor** (Seperti VsCode dan Sublime Text)
- **Extension (opsional)** (Live Preview, Live Server, atau open in browser)

## Cara Menjalankan

1. **Klon repository ini**
``` bash
    git clone https://github.com/Azizi42121/Technity-Company-Profile
```

2. **Buka file utama**
    Buka file index.html menggunakan browser atau dengan extension live server di vscode
